Fundamentos JS

Implementación técnica para el control de aula interactivo.

1. Variables y Tipos de Datos

Uso de const y let. Se implementaron Arrays para almacenar bases de datos estructuradas de alumnos.

const nombres = ["Diego", "Evelyn"]; let registrados = 0;

2. Funciones y Objeto Math

El botón verde ejecuta una función que selecciona aleatoriamente un string del Array y lo inyecta al DOM.

function agregarAleatorio() { let nombre = nombres[Math.random()]; actualizarPanel(); }

3. Condicionales (if/else)

Reglas de negocio. Valida si la capacidad máxima ha sido alcanzada antes de ejecutar el código de registro.

if (registrados < capacidad) { ingresar(); } else { alert("Aula Llena"); }

4. Ciclos (Loops)

Un bucle forEach itera sobre la matriz de estudiantes para crear y renderizar los elementos visuales dinámicamente.
