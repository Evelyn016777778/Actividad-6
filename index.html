Conceptos JavaScript

Implementación teórica y ejemplos de código aplicados al Dashboard dinámico.

1. Variables y Tipos de Datos

Uso de const y let. Además del uso de Arrays para almacenar bases de datos de nombres y apellidos.

const nombres = ["Diego", "Evelyn", "Ana"]; let registrados = 0;

2. Funciones (Generador)

Bloques reutilizables. El botón morado ejecuta una función que escoge un nombre aleatorio del Array y lo inyecta a la interfaz.

function agregarAlumnoAleatorio() { let nombre = nombres[Math.random()]; actualizarPanel(); }

3. Condicionales (if/else)

Controlan el flujo. Si el aula está llena, bloquea la inserción de nuevos alumnos.

if (registrados < capacidad) { ingresar(); } else { alert("Aula Llena"); }

4. Ciclos (Loops)

El ciclo forEach itera sobre la base de datos para renderizar la lista y agregar los íconos de FontAwesome automáticamente.

alumnos.forEach(alumno => { crearBotonUI(alumno); });
